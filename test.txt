# GIT & GITHUB QUICK GLOSSARY

Git
Version control system.
git init

GitHub
Website for hosting Git repositories.

Repository (Repo)
Project folder tracked by Git.
git init
git clone <url>

Status
Shows changed files.
git status

Stage
Prepare files for commit.
git add .
git add <file>

Commit
Save a snapshot of changes.
git commit -m "message"

Log
View commit history.
git log --oneline

Branch
Separate line of development.
git branch feature
git checkout -b feature

Checkout
Switch branches.
git checkout main
git checkout feature

Merge
Combine branches.
git merge feature

Rebase
Replay commits onto another branch.
git rebase main

Cherry-pick
Copy a specific commit.
git cherry-pick <commit-id>

Remote
Online repository.
git remote -v

Origin
Default remote name.
git remote add origin <url>

Clone
Download a repository.
git clone <url>

Fetch
Download changes only.
git fetch

Pull
Download and merge changes.
git pull origin main

Push
Upload commits.
git push origin main

Tag
Mark a release/version.
git tag v1.0

HEAD
Current commit pointer.
HEAD~1 = previous commit

Reset
Move HEAD back.
git reset --soft HEAD~1

Revert
Undo a commit safely.
git revert HEAD

Conflict
When Git cannot merge automatically.

Pull Request (PR)
Request to merge code on GitHub.

Fork
Personal copy of another repository.

.gitignore
Files Git should not track.

Typical Workflow
git pull
git checkout -b feature
git add .
git commit -m "message"
git push origin feature
